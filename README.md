## 🛠️ Ishga tushirish (Dasturchilar uchun)

### 1. Bog'liqliklarni o'rnatish
```bash
npm install
```

### 2. Dasturiy rejimda ishga tushirish
```bash
npm start
# yoki
npx electron .
```
Windows foydalanuvchilari uchun qulay `Start-NeoTerra-Launcher.bat` faylini ikki marta bosish kifoya!

### 3. O'rnatuvchi fayl (.exe installer) yaratish
```bash
npm run dist
```
Tayyor installer `dist/` papkasida paydo bo'ladi.
